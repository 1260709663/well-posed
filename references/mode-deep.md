# 模式二：精读笔记（Deep Read）

**目标**：读完之后，你能不看论文，把主定理的证明在黑板上重写一遍。
**篇幅**：15–30 页。重点不在覆盖所有句子，而在**把跳过的证明补成可验证的链条**。

---

## 结构（严格按序）

### 0. 阅读地图

- 建议阅读顺序（通常不是 1→N：如 §1 → §2.1 → 定理陈述 → §3 主证明 → 回头读 §2.2）。
- 预计难点（2–4 个），每个注明在原文哪一节。
- 前置知识清单：读这篇文章需要会什么（如"需要熟悉 $L^p$–$L^q$ 色散估计""需要知道 Schauder 估计"），标出你若不熟悉该先补什么。

### 1. 记号与约定

一张表，**本文自己定义或非标准的记号**才收入：

| 记号 | 含义 | 出处 |
|---|---|---|
| $\mathcal{E}(t)$ | 总能量 $\frac12\|u\|_{H^1}^2+\int_0^t\|\nabla u\|^2$ | p.5 |
| $A\lesssim B$ | $A\le CB$，$C$ 只依赖 $d,\Omega$ | p.2 |

特别注明：作者用的函数空间定义是否与主流一致（Besov 用热核还是 Littlewood–Paley？$H^s$ 是 $L^2$ 型还是 $W^{s,2}$？）。这类不一致是读不下去的头号原因。

### 2. 问题与主要结果

完整陈述（同模式一的 `thmbox` 规范），并补两样东西：

- **每条定理的"最小反例检验"**：如果把结论里的指数放大一点 / 假设减弱一点，会怎样？这检验定理是否"恰好"。
- **定理之间的关系图**：哪个是主定理，哪个是推论，哪个依赖哪个。

### 3. 预备工具

把论文用到但**没有证明**的外部定理集中列出。每条给：

- 准确陈述（不能只说"引用 [7] 的定理"）
- 出处（文献 + 定理编号 + 页码）
- **所需条件逐条核对**：本文的设定是否满足？维数、正则性、区域光滑性是否匹配？
- 若不匹配 → 这就是真 gap，用 `warnbox` 标出并说明缺什么。

这一段是精读笔记质量的试金石。**大多数人读不下去，就是这里被"by [7]"糊弄过去了。**

### 4. 逐节精读（主体，占全篇 60%）

每节固定四块：

```
【本节任务】一句话：这一节为了得到什么
【原文思路】3–6 行：作者怎么想的，为什么这么绕
【关键步骤还原】编号步骤，公式写全，常数保留依赖关系
【补证】(proofbox) 对跳过的步骤展开
【坑】(gapbox) 该节的隐患、隐含假设、可简化处
```

### 5. 跳步清单（表）

全文扫描一遍，把每处跳步列成表：

| 位置 | 原文措辞 | 类型 | 补法要点 | 难度 |
|---|---|---|---|---|
| p.7 l.12 | "by a density argument" | c | 先在 $C_c^\infty$ 上证，再用弱下半连续性；需 $d\le4$ | ★★ |
| p.9 (3.21) | "standard interpolation" | a | Gagliardo–Nirenberg + Young | ★ |

类型见下面的分类。难度 ★/★★/★★★ 表示补全所需功夫。

### 6. 核心参考文献（3–5 篇）

不是"参考文献里最重要的几篇"，而是**读这篇论文必须握在手上的几篇**。每条格式：

```
[12] Evans, Partial Differential Equations, 2nd ed., §6.3.
  · 为什么核心：本文 §3 的 $H^2$ 估计整段照搬此书定理 3 的框架，只是把 $C^2$ 边界放宽到 Lipschitz
  · 读哪里：§6.3.1（不必读 §6.3.2 的全局估计）
  · 与本文关系：提供了工具，未提供新想法
```

挑选标准（满足任一）：
1. 被反复引用 ≥ 2 次，且每次都承担技术功能。
2. 提供了本文的**起点结果**（本文是在它基础上改进的）。
3. 提供了本文用到的、但未展开证明的关键技术。
4. 是该方向的里程碑（即使只引一次）。

### 7. 遗留问题与可攻击点

3–6 条，每条写"为什么是问题"和"可能的切入点"。这一段是笔记从"读懂"升级到"能做研究"的地方。

---

## 补证明的规范（本 skill 的核心）

### 三类跳步，三种处理

**(a) 常规估计** —— 一行点明即可，不展开。
> 原文"by Cauchy–Schwarz and Young's inequality" → 直接写"用 $ab\le \varepsilon a^2+C_\varepsilon b^2$，取 $\varepsilon=1/2$"。

**(b) 需要具体计算**（分部积分、交换次序、常数追踪、符号判断）—— 逐步写，每一步的等式/不等式都要能验算。这类是读书时最容易卡住的，必须写全。

**(c) 引用外部结果**（"by the results of [12]"、"as in [3, Lemma 4.1]"）—— 最需要功夫：
1. 写出被引定理的**准确形式**（包括所有假设）。
2. 逐条核对本文设定是否满足。
3. 说明如何套用（需要什么变换、取什么参数）。
4. 条件不完全匹配 → 明确写"若采用 [12] 的定理，需要 $C^2$ 边界；本文只有 Lipschitz，此处存在 gap"，用 `warnbox`。

### 标记规则（必须严格执行）

| 标记 | 含义 | 使用场景 |
|---|---|---|
| `\yi` | 原文给出的 | 复述原文证明 |
| `\bz` | 我补出的 | 任何新写的推导 |
| `\ts` | 推断 | 我补的路可能不是作者的路；或对作者意图的猜测 |
| `\gap` | 无法补全 | 我补不出来，或原文本身有错 |
| `\kk` | 隐患 | 隐含假设、边界情形、可简化处 |

**默认原则**：凡不是原文逐字给出的推导，一律标 `\bz`；凡涉及"作者大概想的是"一律加 `\ts`。宁可多标，不可混同。

### 红线

1. **不许偷换假设**。若补证必须额外加条件，写明"需额外假设 X（原文未给）"并标 `\ts`。
2. **不许用"显然""易得""类似可证"**替代推导。要么写，要么标 `\gap` 说明难在哪。
3. **常数不编造**。不确定具体值就写 $C=C(d,\Omega,\|u_0\|_{H^1})$，不要凭空写 $C=4$。
4. **发现原文疑似错误**：必须定位到"p.X, 第 Y 行, 式 (Z)"，说明是笔误（如符号、指数）还是实质错误（如估计方向反了、条件不足），并给出修正。这是笔记最有价值的部分之一，不要回避。
5. 无法判断时，写"此处未能核验"而不是含糊带过。

---

## 写作风格

- 中文讲解，公式与术语英文。
- 每个大段先给"一句话说这一步在干什么"，再上公式。读者先要地图，再要地形。
- 允许第一人称判断："这里我认为可以更简单：直接对 (3.14) 用 Gronwall 即可，不必引入迭代。"

## 排版红线（踩过的坑）

1. **凡是原文没有的编号，展示公式一律用 `equation*`**。用 `equation` 会被自动编成 (1)(2)，与原文的 (3.14) 混在一起，读者无法分辨。原文的编号用 `\tag{3.14}` 手工打。
2. **★ 不能直接写在正文里**（Latin Modern 无此字形，编译后是空白）。用模板里的 `\BS`。
3. 补证里引用原文位置要具体到"p.1027, (3.16)"这种粒度，不要只写"原文说"。
4. 表格用 `longtable` 时要加 `\endhead`，否则跨页表头会丢。
5. 长证明跨页处，`proofbox` 自带 `breakable`，但不要把两个 box 紧挨着放，中间要有一行正文。
