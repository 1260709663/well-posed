# 模式三：导师提问（按章节推进）

**目标**：以导师口头追问的方式，把"读过"逼成"读懂"。
**组织方式**：**跟着论文自己的节号走，一节一组题**，读到哪里就能自测到哪里。
**题量**：20–30 题。**答案紧跟每题**（用户已确认）。

---

## 核心原则：以原文的节结构为骨架

1. **骨架来自论文，不是来自知识点。** 用 `prep.py info` 返回的 `bookmarks` 直接当节列表；没有书签就从正文里找 `^\d+\.` 或 `^§\d` 形式的节标题。**不要用 L1–L4 之类的抽象层次分章**——那是出题的"递进逻辑"，不是"目录"。
2. **每节 3–6 题**，按该节内容密度分配，**不平均用力**。引言节往往信息密度最高，可以给 5–6 题；纯技术节（如某个椭圆正则性引理）2–3 题即可。
3. **节内四级递进**（这是每题难度的来源，不再是章节划分）：
   - ① 设定澄清：这个假设为什么需要？这个空间为什么这么选？
   - ② 结论理解：强在哪？去掉某个条件会怎样？
   - ③ 技术机制：为什么先做 X 再做 Y？哪一步是本质的？
   - ④ 边界与推广：反例、极限情形、能否搬到相邻问题。
4. **跨节问题单独收尾。** 不要把"跨三节的综合判断"硬塞进某一节，统一放到最后的「全局与推广」一节。
5. 节序与原文一致，**不许重排**。用户是拿着 PDF 对照读的，节序一乱就失去了定位价值。

---

## 每节的固定结构

```
\section{§3　一维：特征线构造（原文 p.1026–1028）}

【本节考点】一句话：这一节真正在解决什么
【读法提示】可选，一句：读的时候盯住哪一处

Q13 …（题）
Q14 …（题）

【本节小结】2–3 行：这一节该带走的东西
```

- 节标题里**必须带原文页码**，方便翻回去。
- 【本节考点】不许写成"介绍了……"，要写成"为了证明 $X$ 而建立 $Y$"。
- 【本节小结】是收束，写"若只能记一件事，记这个"。

---

## 每题的固定格式

```
\subsection*{Q7　问题正文（一句话到三句话，短、狠、具体）}
\lvl{§3 技术机制｜$\BS\BS\BS$}
\begin{proofbox}{参考回答}
[3–8 行。必须回答"为什么"，不能只复述结论。含必要公式。]
\end{proofbox}
\wrong{[一行，指出大多数人会怎么答错]}
\ask{[一句，指向更深的地方，不给答案]}
```

- 难度用 ★（概念题）/ ★★（需要推一步）/ ★★★（需要动笔）/ ★★★★（需要判断或构造）。
- 「典型误区」和「追问」**必填**。前者是这套题区别于普通习题集的地方，后者是留给用户继续想的钩子。

---

## 各节出题的侧重（经验规则）

| 节的性质 | 该问什么 | 不该问什么 |
|---|---|---|
| 引言 / 主要结果 | 假设的必要性、结论的强弱、与已有结果的差距、为什么是这个指数/维数 | 证明细节 |
| 预备 / 引理 | 这个引理为什么够用、常数依赖什么、条件能不能弱化 | "引理说了什么"（那叫复述） |
| 技术核心节 | "为什么先做 X 再做 Y"、"这一步的符号从哪来"、"能不能换一种测试函数" | 结论是什么 |
| 构造 / 迭代节 | 收敛因子从哪来、为什么需要 $T$ 充分大、压缩性怎么验证 | 逐行复述构造 |
| 结果 / 应用节 | 结论能否反向、边界情形、与相邻领域的关系 | 重复定理陈述 |
| 结尾 / 讨论 | 作者自己留下的空白、可攻击点 | —— |

---

## 提问风格（关键）

**要像导师，不要像考卷。**

- 短句、口语、直指要害："你说这是标准紧性论证——那紧性到底从哪来？"
- 敢追问细节："第 (3.21) 式第二行，那个不等号方向你确认过吗？"
- 敢质疑："作者说这是最优的，你信吗？"
- 用"如果……会怎样"逼人到边界："如果初始数据只有 $L^2$，你还能走通第 4 步吗？"

**禁止的题型**：
- "本文的主要贡献是什么？"（综述题，无信息量）
- "请简述第二节内容。"（复述题）
- 答案在论文里能直接抄到的题（考的是检索不是理解）
- 把跨节判断塞进单节（会破坏节序的定位功能）

**每节必须有的**：至少 1 题是"只有真读了这一节才答得出"的细节题——比如某一步为什么取这个系数、某个常数为什么只能依赖这些量。这类题是整套题的价值所在。

## 结尾：两件收尾工作

### 1. 全局与推广（3–5 题）

跨节问题集中在这里：整篇文章的方法边界、与相邻工作的关系、能否推广到别的方程/区域、作者留下的空白。难度标 ★★★★。

### 2. 薄弱环节诊断（按节映射）

| 若这一节的题大多答不出 | 说明 | 建议 |
|---|---|---|
| §2 | 没抓住势井机制的前提 | 回去补 Sattinger 的不变集论证 |
| §3 | 一维构造没走通 | 手工推一遍能量通量恒等式 |

表格按**实际论文的节**填，不要照抄上面两行——那只是示例。

最后给一句总评：这篇论文的难度对什么水平的人合适，读它最该带走的一个技术是什么。
