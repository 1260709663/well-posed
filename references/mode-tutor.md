# 模式三：导师提问（Tutor）

**目标**：以导师口头追问的方式，把"读过"逼成"读懂"。
**题量**：20–28 题。**答案紧跟每题**（用户已确认）。

---

## 四层题库

| 层级 | 名称 | 题数 | 难度 | 考什么 |
|---|---|---|---|---|
| L1 | 设定与记号 | 4–6 | ★ | 是否真的看清了问题 |
| L2 | 定理理解 | 6–8 | ★★ | 是否理解结论的强弱与边界 |
| L3 | 证明技术 | 7–10 | ★★★ | 是否抓住了证明的机制 |
| L4 | 边界与推广 | 4–6 | ★★★★ | 能否把结果放到领域地图上 |

### L1 设定与记号（好问题长什么样）

- 为什么要假设 $\Omega$ 是 Lipschitz 而不是 $C^1$？这个宽松在哪里被用到？
- 作者为什么选 $H^1_0$ 而不是 $H^1$？边界条件在哪一步进来？
- (2.3) 里的常数 $C$ 依赖哪些量？作者说"只依赖 $d$"，真的吗？

### L2 定理理解

- 定理 1.1 的结论里，$\|u(t)\|_{H^1}$ 的界是"对每个 $t$"还是"一致对 $t$"？差别在哪？
- 把假设 $s>1/2$ 降到 $s>0$，哪一步会崩？
- 作者说"sharp"，你能用 scaling 验证吗？
- 定理 1.3 的唯一性是否依赖定理 1.1 的存在性？顺序能不能反？

### L3 证明技术

- 第 3 步为什么先做截断 $u^\varepsilon$ 再取极限？不截断会缺什么紧性？
- 估计 (3.17) 里 $\varepsilon^{-1}$ 的损失从哪来？能否用插值避免？
- 这里的测试函数为什么可以取 $u_t$？正则性够吗？
- 如果把 Galerkin 维数先取极限再取时间极限，会出什么问题？
- 全文哪个估计是"唯一真正困难的"，为什么其他都是例行公事？

### L4 边界与推广

- 给出一个反例说明 $d=5$ 时结论不成立（或说明为什么构造不出来）。
- 若把 $\Delta$ 换成 $\Delta^2$（双调和），哪些步骤需要改？
- 这篇的方法能否用于 Navier–Stokes？卡在哪？
- 与 [8] 的方法相比，本文的优势是本质的还是技术性的？

## 每题的固定格式

```
\subsection*{Q7 \hfill {\small\normalsize L3｜★★}}
[问题正文：一句话到三句话，短、狠、具体]
\begin{proofbox}{参考回答}
[3–8 行。必须回答"为什么"，不能只复述结论。含必要公式。]
\end{proofbox}
{\small\color{warncolor}典型误区：} {\small [一行，指出大多数人会怎么答错]}
{\small\color{notecolor}追问：} {\small [一句，指向更深的地方，不给答案]}
```

题目本身用 `\subsection*` 或加粗编号，答案用 `proofbox`（绿框），误区用红字小字，追问灰字。

---

## 提问风格（关键）

**要像导师，不要像考卷。**

- 短句、口语、直指要害："你说这是标准紧性论证——那紧性到底从哪来？"
- 敢追问细节："第 (3.21) 式第二行，那个不等号方向你确认过吗？"
- 敢质疑："作者说这是最优的，你信吗？"
- 用"如果……会怎样"逼人到边界："如果初始数据只有 $L^2$，你还能走通第 4 步吗？"

**禁止的题型**：
- "本文的主要贡献是什么？"（综述题，无信息量）
- "请简述第二节内容。"（复述题）
- 答案在论文里能直接抄到的题（那考的是检索不是理解）

**必须有的**：至少 3 题针对本文独有的技术细节，只有真读懂这篇才答得出（比如"作者为何在 (4.8) 引入权重 $\langle x\rangle^{-1}$"）。这类题是这套题的价值所在。
